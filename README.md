# Descrição

Essa é uma aplicação front-end  com funcionalidades de CRUD para produtos e 
categorias.

# Funcionalidades

**Produtos**
- Listagem com filtros por nome e categoria 
- Criação de novo produto 
- Edição do nome do produto 
- Exclusão de produto 
- Página de detalhes do produto

**Categorias**
- Listagem de categorias
- Criação de novo categoria 
- Edição de categoria
- Exclusão de categoria 

## Variaveis de ambiente

Para o uso dessa aplicação é necessario a criação de um arquivo denominado **.env.local** na raiz do projeto e definição das seguintes variaveis de ambiente no arquivo: 

`NEXT_PUBLIC_API_URL`

`NEXT_PUBLIC_API_KEY`

## Comandos importantes

Para instalar todos os pacotes necessarios para executar a aplicação localmente execute o comando:

```bash
npm install
```

Para rodar localmente a aplicação execute o seguinte comando:

```bash
npm run dev
```


Para fazer a implantação (build) da aplicação execute o seguinte comando: 

```bash
npm run build
```



Para executar localmente a implantação

```bash
npm start
```
